איך מקבלים את האפליקציה (בלי Android Studio):

1. פותחים חשבון חינמי ב-github.com ויוצרים Repository חדש (New repository).
2. מחלצים את ה-ZIP במחשב. בדף ה-Repository בוחרים "uploading an existing file"
   וגוררים פנימה את *כל* התוכן של התיקייה (כולל התיקייה .github). לוחצים Commit.
3. נכנסים ללשונית Actions. הבנייה מתחילה לבד ואורכת כמה דקות.
4. כשהיא מסתיימת (וי ירוק) נכנסים אליה, גוללים ל-Artifacts ומורידים jelly-apk.
5. מחלצים את ה-ZIP שהורד, מעבירים את app-debug.apk לטלפון ומתקינים
   (מאשרים "התקנה ממקורות לא ידועים").
6. פותחים את Jelly, לוחצים "הפעל את הג'לי" ומאשרים "הצגה מעל יישומים אחרים".
